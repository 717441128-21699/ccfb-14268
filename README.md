# 墨鉴 · 多波段可疑文书墨水分层检验工作站

面向文检仪多波段成像场景的墨水分离工具。一份文书压在玻璃下不动，按 **紫外 365 / 蓝光 420 / 蓝光 470 / 绿光 535 / 红光 625 / 近红外 850nm** 六个波段各拍一张，逐像素按各波段反射比解混，把两种墨水分到两个图层，使同色笔描改、后加笔画显形。

## 解决的问题

- 合同被同色笔涂改、描红，可见光下两墨目视同色，只能靠放大镜在多波段光源下逐笔辨认；
- 本工具利用墨水的**同色异谱**特征（如染料型黑色中性笔在近红外透明、颜料型签字笔近红外仍吸收），在吸光度空间做两端元非负最小二乘解混，输出两个独立丰度层。

## 技术方案

| 环节 | 实现 |
| --- | --- |
| 成像模型 | 反射率先转相对纸张的吸光度 `y = -ln(R墨/R纸)`，Beer–Lambert 线性混合 `y = k1·c1 + k2·c2` |
| 解混算法 | 两端元 **NNLS 解析解**：二维只有 4 个候选活动集 {1,2}/{1}/{2}/{}，无迭代、可逐像素并行 |
| 计算位置 | **WebGL2 片元着色器**，六波段 R16F 纹理数组输入，MRT 一次输出 c1/c2/残差/总墨量四张 R32F 图 |
| 波段权重 | 全局权重 + 最多 8 个 ROI 区域权重，走 uniform 数组在 shader 内逐像素切换 |
| CPU 参考 | `src/core/nnls.ts` 与 GLSL 逐行对应，单测与无头浏览器交叉验证数值一致 |
| 合成样本 | 纸张纤维/云斑纹理 + 6 类墨水光谱反射曲线 + CJK 字体笔画覆盖率，带真值掩膜 |

### 目录结构

```
src/core/        纯 TS 数学与合成（Node/浏览器通用）
  bands.ts       六波段定义
  spectra.ts     墨水光谱库、纸张基线、吸光度
  nnls.ts        NNLS 解析解（CPU 参考）
  synthetic.ts   合成文书生成器（含真值掩膜）
  metrics.ts     CPU 分离管线与串色率评测
  raster.ts      覆盖率光栅化、亚像素平移
src/webgl/       WebGL2 引擎
  shaders.ts     分离 Pass + 显示 Pass GLSL
  SeparationEngine.ts
  floatHalf.ts   float32→float16（匹配 10~12bit 仪器量化）
src/ui/          React 工作台（案件/文书/ROI/标注/报告）
gpu-check/       无头 Chromium：GPU vs CPU 一致性、ROI、A4 计时
e2e/             Playwright 端到端冒烟
```

## 操作流程

1. **新建案件** → 案件列表页建档；
2. **新建检验文书**：
   - *合成测试样本*：三种场景（同色笔涂改描红 / 金额数字篡改 / 印文交叠），自动带真值与串色率评测；
   - *导入六波段照片*：按六个波段各导入一张同尺寸、已配准的图；
3. 工作台选择两个**墨水端元**（光谱库 6 种墨水），查看双墨水叠加（红=原文墨、青=后加墨）、单层、残差、RGB；
4. **框选 ROI** 后对该区域单独调六个波段权重；
5. 用标注框/箭头/文字标记可疑笔画；
6. **生成结论页**：导出带案件信息、指标、图、检验意见的 PNG 报告，以及 JSON 检验记录。

## 验收指标（实测）

| 指标 | 要求 | 实测（无头 Chromium / SwiftShader） |
| --- | --- | --- |
| 综合串色率 | < 5% | 三场景 1.9% / 2.9% / 4.5%（工作台尺寸），A4@200DPI 2.85% |
| GPU↔CPU 平均丰度偏差 | — | < 0.0003（最大 < 0.001） |
| A4@200DPI（1654×2339，387 万像素）分离耗时 | ≤ 3 s | 分离 Pass 亚毫秒~毫秒级（软件渲染器；真机 GPU 同样为单 Pass） |
| 纸张误判率 | — | < 0.12% |

> 串色率口径：在"仅含某一种墨水"的真值像素上，对侧层丰度占该像素总墨量比例的均值。

## 命令

```bash
npm install
npm run dev        # 本地开发
npm run test       # 纯数学单测（NNLS、串色率、float16）
npm run gpu:check  # 无头浏览器 GPU/CPU 一致性 + A4 计时
npm run e2e        # 端到端冒烟（建档→分离→ROI→标注→报告）
npm run verify     # 类型检查 + 单测 + GPU 校验
npm run build
```

## 关键工程约束

- 波段纹理用 **R16F 而非 R8**：暗反射率经 `-ln` 会放大 8bit 量化误差，R16F 对齐仪器 10–12bit 动态范围；
- R32F 输出纹理在 WebGL2 核心不可线性过滤，过滤模式必须 `NEAREST`；
- 源图上传用 `UNPACK_FLIP_Y_WEBGL` 统一到 GL 左下原点，ROI 矩形 y 坐标在引擎内做 `1-y` 转换。

## 局限与后续

- 当前为两端元模型；三种及以上墨水需扩展为 K 端元 NNLS（活动集枚举随 K 增长，建议改投影梯度迭代）；
- 真实文书无真值掩膜，串色率指标仅合成样本可得；端元目前取自光谱库，后续可加图像上点选采样自定义端元；
- 波段间配准偏移已在合成器支持（`bandShifts`），UI 上的交互式配准微调待补。
